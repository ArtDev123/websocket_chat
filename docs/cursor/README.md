# Cursor — промпт и plan mode

Чат уже разрезан на [user и chat](../split/README.md), на оба сервиса повешен [пайплайн](../pipelines/README.md). Здесь код не пишем. Берём одну фичу из трёх, собираем промпт по чеклисту и отдаём его Cursor в plan mode. Агент сначала приносит план, код появляется только после того, как план принят.

Расчёт на **~40 минут**.

## Как читать

1. Сначала [guide.md](guide.md) — из чего состоит промпт и что plan mode делает иначе, чем обычный чат.
2. Затем шаги по порядку. Не переходите дальше, пока не отметили «✅ Готово».

В каждом шаге:

1. **Задача** — что должно получиться.
2. **Теория** — своими словами, зачем так.
3. **Код** — текст, который пишете вы: промпт, а не Python.
4. **Разбор кода** — что в этом тексте делает каждая часть.
5. **✅ Проверка** — чеклист до того, как нажать отправку.
